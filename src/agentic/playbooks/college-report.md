# College report / assignment playbook
1. Restate the question and any constraints (length, format, deadline) before writing.
2. Outline first: headings with one line each. Confirm with the user if the scope is unclear.
3. Write in the user's own plain style; explain steps, define terms, and avoid padding.
4. For facts or claims, say where they come from; never invent citations or numbers.
5. End with a short summary and a checklist of what to verify before submitting.
