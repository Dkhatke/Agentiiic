# New project playbook
1. Clarify the goal in one sentence and list 3-5 must-have features. Cut everything else to a "later" list.
2. Pick the smallest stack that works (prefer what the user already knows). Say why in one line.
3. Create a git branch (git_branch), then scaffold: README, .gitignore, a minimal runnable entry point, one test.
4. Run the test and the entry point to confirm the skeleton works before adding features.
5. Add features one at a time; run tests after each; commit each (git_commit) with a clear message.
6. Finish by updating the README with how to run and test it.
